渐进记号

本节介绍了一些常见的渐进记号，并介绍了它们的使用方法。

Θ\ThetaΘ 记号

对于一个给定的函数 g(n)g(n)g(n)，用 Θ(g(n))\Theta(g(n))Θ(g(n)) 来表示以下函数的集合：

Θ(g(n))={f(n)∣∃c1,c2>0,n0,s.t.∀n≥n0,0≤c1g(n)≤f(n)≤c2g(n)}\Theta(g(n)) = \left \{f(n)\mid \exist c_1,c_2>0,n_0,s.t.\forall n\ge n_0,0\le c_1g(n)\le f(n)\le c_2g(n)\right \} Θ(g(n))={f(n)∣∃c1​,c2​>0,n0​,s.t.∀n≥n0​,0≤c1​g(n)≤f(n)≤c2​g(n)}

尽管 Θ(g(n))\Theta(g(n))Θ(g(n)) 是一个集合，我们也可以使用 f(n)=Θ(g(n))f(n) = \Theta(g(n))f(n)=Θ(g(n)) 来表示一个满足条件的 f(n)f(n)f(n)。f(n)f(n)f(n) 和 g(n)g(n)g(n) 的关系如下图所示：

换句话说，对所有的 n≥n0n\ge n_0n≥n0​，f(n)f(n)f(n) 在一个常量因子等于 g(n)g(n)g(n)，我们称 g(n)g(n)g(n) 是 f(n)f(n)f(n) 的一个渐进紧确界。既然如此，我们完全可以抛弃这个常量因子，只从高阶项来考虑渐进关系，也就是说，Θ\ThetaΘ 记号相当于扔掉低阶项并忽略最高项前的系数。例如：

12n2−3n=Θ(n2)\frac{1}{2}n^2-3n=\Theta(n^2) 21​n2−3n=Θ(n2)

接下来我们形式化地用定义证明这个式子，首先先确定 c1,c2,n0c_1,c_2,n_0c1​,c2​,n0​ 这三个常量，对 ∀n≥n0\forall n\ge n_0∀n≥n0​，有：

c1n2≤12n2−3n≤c2n2c_1n^2\le \frac{1}{2}n^2-3n\le c_2n^2 c1​n2≤21​n2−3n≤c2​n2

也就是：

c1≤12−3n≤c2c_1\le \frac{1}{2}-\frac{3}{n}\le c_2 c1​≤21​−n3​≤c2​

只需要选择 c1=114,c2=12,n0=7c_1=\frac{1}{14},c_2=\frac{1}{2},n_0=7c1​=141​,c2​=21​,n0​=7 即可证明。对于其它的例子，有点类似于数学分析中极限的 ϵ−N\epsilon-Nϵ−N 语言，这里不再赘述。

OOO 记号

前文的 Θ\ThetaΘ 记号相当于给出了函数在一个常量因子内的上界和下界，当只有一个渐进上界时，使用 OOO 记号，也就是说，O(g(n))O(g(n))O(g(n)) 是如下的集合：

O(g(n))={f(n)∣∃c>0,n0,s.t.∀n≥n0,0≤f(n)≤cg(n)}O(g(n)) = \left \{f(n)\mid \exist c>0,n_0,s.t.\forall n\ge n_0,0\le f(n)\le cg(n)\right \} O(g(n))={f(n)∣∃c>0,n0​,s.t.∀n≥n0​,0≤f(n)≤cg(n)}

我们称 g(n)g(n)g(n) 为 f(n)f(n)f(n) 的渐进上界。

由定义可知，Θ\ThetaΘ 记号是一个比 OOO 记号更强的概念，用集合论的写法，就是 Θ(g(n))⊆O(g(n))\Theta(g(n))\subseteq O(g(n))Θ(g(n))⊆O(g(n))。同时，一个 f(n)f(n)f(n) 可以有很多个渐进上界，例如，我们很容易证明 f(n)=an+b=O(n)f(n)=an+b=O(n)f(n)=an+b=O(n)，也很容易证明 f(n)=an+b=O(n2)f(n)=an+b=O(n^2)f(n)=an+b=O(n2)，我们在算法复杂度分析中更关注渐进上确界，也就是 O(n)O(n)O(n)。

OOO 记号太常用了，以至于我们在分析算法的时间复杂度和空间复杂度时，基本都使用 OOO 记号。由于其代表的时函数的渐进上确界，在多数情况下反映的是算法的最坏情况运行时间和运行空间。例如，插入排序算法的实现中有一个双重嵌套循环，对于特定规模 nnn 的输入，它的运行时间可能并不能到达 O(n2)O(n^2)O(n2) 的量级，但我们说其时间复杂度为 O(n2)O(n^2)O(n2)，意指对于任意规模 nnn 的输入，其运行时间的上确界都是 O(n2)O(n^2)O(n2)。

Ω\OmegaΩ 记号

类似于 OOO 记号，Ω\OmegaΩ 记号表示的是算法的渐进下界，也就是如下的集合：

Ω(g(n))={f(n)∣∃c>0,n0,s.t.∀n≥n0,0≤cg(n)≤f(n)}\Omega(g(n)) = \left \{f(n)\mid \exist c>0,n_0,s.t.\forall n\ge n_0,0\le cg(n)\le f(n)\right \} Ω(g(n))={f(n)∣∃c>0,n0​,s.t.∀n≥n0​,0≤cg(n)≤f(n)}

对比着看，Ω\OmegaΩ 记号可以用来表达算法最好情况下的运行时间和运行空间度，例如，插入排序的运行时间为 Ω(n)\Omega(n)Ω(n)。

关于 Θ\ThetaΘ 记号、OOO 记号和 Ω\OmegaΩ 记号，显然有如下定理：

f(n)=Θ(g(n))⇔f(n)=O(g(n))且f(n)=Ω(g(n))f(n) = \Theta(g(n)) \Leftrightarrow f(n) = O(g(n)) \text{且} f(n) = \Omega(g(n)) f(n)=Θ(g(n))⇔f(n)=O(g(n))且f(n)=Ω(g(n))

ooo 记号

和 OOO 记号对应，表示 O(g(n))O(g(n))O(g(n)) 的集合中不是渐进上确界的那一部分函数。用数学语言说，若 f(n)=o(g(n))f(n) = o(g(n))f(n)=o(g(n))，则有：

lim⁡n→∞f(n)g(n)=0\lim_{n\to \infty} \frac{f(n)}{g(n)}=0 n→∞lim​g(n)f(n)​=0

ω\omegaω 记号

和 Ω\OmegaΩ 记号对应，表示 Ω(g(n))\Omega(g(n))Ω(g(n)) 的集合中不是渐进下确界的那一部分函数。用数学语言说，若 f(n)=ω(g(n))f(n) = \omega(g(n))f(n)=ω(g(n))，则有：

lim⁡n→∞f(n)g(n)=∞\lim_{n\to \infty} \frac{f(n)}{g(n)}=\infty n→∞lim​g(n)f(n)​=∞

等式和不等式中的渐进记号

渐进符号可以用于数学公式中，例如 2n2+3n+1=2n2+Θ(n)2n^2+3n+1=2n^2+\Theta(n)2n2+3n+1=2n2+Θ(n)，这是因为 3n+1=Θ(n)3n+1=\Theta(n)3n+1=Θ(n)，这就是虽然 Θ(g(n))\Theta(g(n))Θ(g(n)) 是一个集合，但是我们仍然使用 f(n)=Θ(g(n))f(n)=\Theta(g(n))f(n)=Θ(g(n)) 而很少使用 f(n)∈Θ(g(n))f(n)\in \Theta(g(n))f(n)∈Θ(g(n))。

这种表示是有好处的，例如在归并排序中，每一次分治地将一个大的排序问题划分成两个小的排序问题，且两个子问题和原问题的算法是一模一样的。我们用 T(n)T(n)T(n) 来表示输入规模为 nnn 的算法的最坏情况运行时间，则根据归并排序的分治过程，我们有如下的递归式：

T(n)=2T(n/2)+Θ(n)T(n) = 2T(n/2)+\Theta(n) T(n)=2T(n/2)+Θ(n)

其中，2T(n/2)2T(n/2)2T(n/2) 表示两个子问题所需要的时间，Θ(n)\Theta(n)Θ(n) 表示最后的Merge操作，即将两个升序数组合并成一个升序数组的过程，这一部分的时间和问题规模成正比。

渐进记号的性质

渐进记号可以看作两个函数之间的二元关系，它具有自反性、对称性以及传递性，以 Θ\ThetaΘ 记号为例：

f(n)=Θ(g(n)),g(n)=Θ(h(n))⇒f(n)=Θ(h(n))f(n)=Θ(f(n))f(n)=Θ(g(n))⇔g(n)=Θ(f(n))\begin{aligned} f(n)=\Theta(g(n)),g(n) &= \Theta(h(n))\Rightarrow f(n) = \Theta(h(n)) \\ f(n) &= \Theta(f(n)) \\ f(n) = \Theta(g(n)) &\Leftrightarrow g(n) = \Theta(f(n)) \end{aligned} f(n)=Θ(g(n)),g(n)f(n)f(n)=Θ(g(n))​=Θ(h(n))⇒f(n)=Θ(h(n))=Θ(f(n))⇔g(n)=Θ(f(n))​

但是对于 OOO 记号和 Ω\OmegaΩ 记号，对称性要体现在转置上：

f(n)=O(g(n))⇔g(n)=Ω(f(n))\begin{aligned} f(n) = O(g(n)) \Leftrightarrow g(n) = \Omega(f(n)) \end{aligned} f(n)=O(g(n))⇔g(n)=Ω(f(n))​
